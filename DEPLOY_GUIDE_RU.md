## Шаг 2. Render — бесплатный бэкенд

1. **render.com** → Get Started → **Sign up with GitHub** (карта не нужна).
2. Dashboard → **New +** → **Web Service** → Connect GitHub → выбери `loltube-v8`.
3. Настройки:
   - **Name:** `loltube-v8` (станет частью адреса)
   - **Language/Runtime:** Node
   - **Region:** Frankfurt (EU Central)
   - **Branch:** `main`
   - **Root Directory:** оставь пустым
   - **Build Command:** `npm install --omit=dev`
   - **Start Command:** `node server.js`
   - **Instance Type:** **Free**
4. **Environment Variables** → Add:
   - `NODE_ENV` = `production`
   - `JWT_SECRET` = придумай длинную строку (например `loltube-v8-secret-2026-x7k2p9`). Никому не диктуй.
   - *(три `CLOUDINARY_*` добавишь на шаге 3 — можно сразу)*
5. **Create Web Service** → подожди 3–5 минут, пока статус не станет **Live**.
6. Сверху скопируй URL — например `https://loltube-v8.onrender.com`.
7. Проверка: открой URL — должен открыться **сам сайт** (сервис отдаёт и сайт, и API), и `.../api/config` — JSON с `"version":"2.0"`.

> **Хочешь кнопкой?** В архиве есть `render.yaml`: New + → **Blueprint** → выбери репо → Apply — Render сам создаст сервис с нужными настройками. Останется вписать Cloudinary-переменные.

> ⚠️ **Важно про часы:** бесплатно даётся **750 часов на все сервисы** в месяц. Круглосуточный сервис ест ~730 ч — влезает впритык. **Держи только ОДИН работающий сервис**: старый `loltube-backend` лучше поставить на паузу или удалить, иначе два круглосуточных съедят ~1460 ч и Render приостановит оба до конца месяца.

## Шаг 3. Cloudinary — те самые бесплатные 25 ГБ

**Зачем:** у Render free диск «одноразовый» — при каждом перезапуске загруженные файлы стираются. Cloudinary хранит файлы постоянно.

1. **cloudinary.com** → **Sign up for free** (почта). Карта **НЕ нужна**.
2. Открой **Dashboard** (console.cloudinary.com → Dashboard).
3. Скопируй три значения:
   - **Cloud Name** (вида `dxxxxxxx`)
   - **API Key** (цифры)
   - **API Secret** (нажми «глаз», чтобы показать)
4. Render → твой сервис → **Environment** → **Add Environment Variable** (по одной):
   - `CLOUDINARY_CLOUD_NAME` = ...
   - `CLOUDINARY_API_KEY` = ...
   - `CLOUDINARY_API_SECRET` = ...
5. **Save Changes** → сервис сам передеплоится (2–3 минуты).
6. Проверка: `.../api/config` → `"storage":{"cloudinary":true,"persistent":true}`. В логах Render появится строка `Cloudinary enabled ...`.

**Лимиты free:** 25 кредитов в месяц. 1 кредит = **1 ГБ хранения ИЛИ 1 ГБ трафика ИЛИ 1000 трансформаций**. Грубо: «25 ГБ» — это если считать только хранение; за просмотры тоже списываются кредиты (видео-трафик — 1 ГБ за кредит). Для теста и друзей — с запасом.

**Нюансы:**
- Cloudinary подхватывает **только новые** загрузки. Всё, что лежало локально до подключения, не переедет.
- Аватарки, обложки, музыка и видео — всё уходит в Cloudinary автоматически (код уже готов, я его проверил).

Render free засыпает через **15 минут** без запросов, первый заход после сна — до **60 секунд**. Лечится бесплатным пингом каждые 5 минут.

**UptimeRobot (рекомендую):**
1. **uptimerobot.com** → Sign up free (почта).
2. Dashboard → **+ New monitor** → Monitor Type: **HTTP(S)**.
3. Friendly Name: `LolTube`.
4. URL: `https://loltube-v8.onrender.com/api/config` *(твой адрес с шага 2)*
5. Monitoring Interval: **5 minutes** (минимум на бесплатном).
6. **Create Monitor**.

Всё: пинг идёт круглосуточно — сервер вечно бодр. Бонус: если сервер упадёт — UptimeRobot пришлёт письмо.

**Запасной вариант:** **cron-job.org** (бесплатно) — Create cronjob → URL тот же → интервал 5–10 минут.

## 🎥 OBS → ТВ-ФАНТОМАС (ты выбрал «вещаю сам»)

Наш плеер ест **HLS-ссылку (`.m3u8`)**. Значит: стримишь из OBS туда, где есть HLS-выход → вставляешь ссылку в **АДМИНКА → ЭФИР** → страница ТВ-ФАНТОМАС играет.

Куда стримить из OBS:

| Сервис | Плюсы | Минус |
|---|---|---|
| **YouTube Live** | 2 клика, RTMP-ключ в Studio | ссылка просмотра «плавающая» (~6 ч) |
| **VK Видео Live** | лучший доступ из РФ | ссылка тоже плавающая |
| **Twitch** | просто | в РФ нужен VPN/прокси |
| свой VPS (nginx-rtmp / Owncast) | всё своё, живёт вечно | надо поднять сервер |

1. OBS → **Настройки → Вещание** → Сервис: «Настраиваемый…» → вбиваешь **Server (RTMP)** + **Stream Key** из Studio сервиса.
2. Запусти эфир из OBS. Получи адрес просмотра.
3. Если это прямая `.m3u8` — вставляй в приложении: **АДМИНКА → ЭФИР → HLS URL → Сохранить** (включать эфир может только админ).
4. Если ссылка плавающая или с защитой (YouTube/VK) — **скинь мне её**: я допилю на бэке «резолвер» (сервер сам достаёт свежий m3u8) + **HLS-прокси** (обход CORS) — и тогда вставлять можно будет что угодно.

## FAQ

**Первый заход долгий — почему?** Сервис спал (нет пинга) или же Render «просыпается» ~60 сек. С UptimeRobot — быстро всегда.
**Видео пропало после перезапуска.** Не заданы `CLOUDINARY_*` переменные, либо файл заливался до их подключения. Проверь `/api/config`.
**Render приостановил сервис до конца месяца.** Истрачены 750 часов — скорее всего работает второй сервис. Останови лишний.
**Хочу свой домен.** Render → Settings → Custom Domain — бесплатно и на free-плане (домен надо купить отдельно).
**Почему `npm install --omit=dev`?** Чтобы Render не тянул тестовые библиотеки (jsdom и т.п.) — сборка быстрее.
**Надо ли задавать PORT?** Нет. Render сам передаёт порт, сервер его читает. Ничего добавлять не нужно.
**Можно ли поменять название сервиса позже?** Да, но URL изменится — придётся при смене сказать мне, и обновить пинг в UptimeRobot.
