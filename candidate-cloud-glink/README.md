# GLINK relay на Cloudinary — кандидат, не релиз

Этот каталог готовит долговечный временный relay для одного сервиса Render Free. Он ещё не подключён к production и не меняет работающий LOLTUBE.

- Части шифротекста сохраняются как authenticated raw-объекты в отдельном namespace. Успех загрузки возвращается только после записи и проверки частей и неизменяемой ревизии. `Range` работает на границах частей. Индекс сессии использует хэш её случайного идентификатора.
- Очередь зашифрованных Wi-Fi offers сохраняется через отдельный журнал, успешный ответ ожидает записи. Токены регистрации, challenge и presence не сохраняются; после рестарта клиент заново авторизуется.
- Истёкшие завершённые или явно закрытые сессии удаляются поэтапно; во время активного локального запроса удаление не начинается, а незавершённые загрузки автоматически не удаляются. Отдельный tombstone остаётся. Очистка изолирована от других namespace.
- Локально 18 проверок relay/storage/offers и 4 интеграционных проверки двух изолированных браузеров с реальной GSENC1-передачей; в отдельном случайном префиксе настоящего Cloudinary проверены часть 6 МиБ, SIGKILL, продолжение, Range и удаление по сроку. Созданные synthetic-объекты удалены.

## Прежде чем включать

Cloudinary `overwrite:false` прошёл гонки, но гарантия атомарного conditional-create и read-after-write в конфликте не подтверждена. Без fencing двух экземпляров нельзя считать хранение полностью защищённым от гонок. Требуются безопасный общий запуск и drain, интеграция с LOLTUBE/G+, ограничение злоупотреблений и расходов, восстановление при недоступном резерве и проверка Android/NFC на устройствах. Render Free может засыпать и имеет общие лимиты workspace; 25 Cloudinary credits не являются гарантированным 25-ГБ диском.

Запуск локальных тестов с Node 24: `node --test glink-cloud/*.test.js`. Браузерный тест требует `jsdom@26` и `fake-indexeddb@6`, остальные зависимости для SQLite берутся из `gplus-cloud`. В тестах только искусственные данные. Ключи и подписанные URL не выводить и не добавлять в Git.
